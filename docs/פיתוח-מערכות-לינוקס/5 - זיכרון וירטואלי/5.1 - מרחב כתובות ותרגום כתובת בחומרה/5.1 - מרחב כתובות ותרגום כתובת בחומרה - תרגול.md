# תרגול מיפוי ונגיעה בעמודים

שנו את הניסוי לשלוש עצירות: אחרי מיפוי, אחרי קריאה מכל עמוד ואחרי כתיבה לכל עמוד. שמרו את מדדי הזיכרון ואת מספר ה־faults, והסבירו מדוע קריאה של אפסים וכתיבה פרטית יכולות להוביל לתוצאות שונות.

בצעו את אותו מספר גישות פעם ברצף צפוף ופעם בצעד של עמוד. הקפידו להפריד בין מספר הבייטים שביקשתם לבין מספר העמודים שנגעתם בהם. אל תסיקו ממדידת זמן אחת מה היה שיעור הפגיעות ב־TLB.

ציירו את מסלול הגישה עבור פגיעת TLB, החטאת TLB עם טבלה תקפה ו־page fault שדורש טיפול קרנל. ציינו באיזה מסלול חייבת להתרחש החלפת משימה, ובאיזה מסלול אין לכך הכרח.

# תרגול הכנת זיכרון מראש

הריצו את עטיפת הנעילה עם אזור קטן ותעדו את מגבלת המשאב. הגדילו את הבקשה באופן מבוקר בתוך סביבת תרגיל, ובדקו שהכשל נשמר כשגיאה ולא גורם להמשך עבודה תחת הנחה שהאזור נעול.

השוו מסלול עם נגיעה מוקדמת למסלול ללא נגיעה, ושמרו בנפרד זמן הכנה וזמן שימוש. הסבירו מדוע מדידה שמתחילה רק אחרי ההכנה אינה מודדת את המחיר הכולל של השירות.

תכננו ניסוי THP עם אותה כמות נתונים ואותו דפוס גישה. רשמו איזה מידע יוכיח שהמדיניות השפיעה על המיפוי ואיזה מידע יוכיח שהשינוי הועיל לעומס.

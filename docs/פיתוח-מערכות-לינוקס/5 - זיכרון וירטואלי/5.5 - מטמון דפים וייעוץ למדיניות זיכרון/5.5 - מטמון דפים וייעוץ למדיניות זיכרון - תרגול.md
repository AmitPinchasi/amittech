# תרגול החזרת עמודים לשימוש חוזר

מדדו מפת כתובות, זיכרון תושב ו־faults לפני מילוי המיפוי, אחרי מילויו, אחרי `MADV_DONTNEED` ואחרי כתיבה חוזרת. הסבירו איזה מדד אמור להישאר יציב ואיזה יכול להשתנות.

כתבו בדיקת קומפילציה שלילית שמחזיקה פרוסה מהמיפוי, קוראת ל־`discard_contents` ואז משתמשת בפרוסה הישנה. נמקו מדוע מתודה שמקבלת `&self` הייתה חוזה מסוכן יותר כאן.

תכננו ניסוי השוואה בין קריאה סדרתית לקריאה אקראית של קובץ ייעודי. ציינו איך תפרידו בין מצב cache לבין שינוי האלגוריתם, ואילו תוצאות עשויות להראות שהרמז לא עזר.

# פתרון החזרת עמודים לשימוש חוזר

הקטע הבא מיועד להיכשל כאשר משתמשים בהגדרת `Mapping` והמתודה מההרצאה. ההשאלה המשותפת עדיין דרושה אחרי הקריאה שמבקשת השאלה משתנה.

```rust
fn main() -> io::Result<()> {
    let mut memory = Mapping::new(4096)?;
    let bytes = memory.bytes();
    memory.discard_contents()?;
    println!("{}", bytes[0]);
    Ok(())
}
```

מפת הכתובות יכולה להישאר זהה משום שלא ביצענו `munmap`. לעומת זאת, מצב תושב ומוני faults יכולים להשתנות כאשר עמודים נזרקים ונוצרים מחדש. תוצאה של רמז מדיניות נבחנת על פני כמה הרצות ובמצב עומס מייצג, ולא באמצעות הבטחה שכל קריאה סדרתית חייבת להיות מהירה יותר בכל מערכת.

# פתרון תכונות ומרוצי גודל

את ענף ההצלחה מחליפים בבדיקה הבאה בתוך הלולאה. היא מזהה את המקרה שבו קריאה עם גודל אפס חזרה רק עם הגודל החדש.

```rust
if count >= 0 {
    if count as usize > bytes.len() { continue; }
    bytes.truncate(count as usize);
    return Ok(bytes);
}
```

שני hard links מתייחסים לאותו אובייקט, ולכן תכונה שנשמרת על ה־inode נראית דרך שניהם. עותק של התוכן יוצר אובייקט אחר, ואינו משמר אוטומטית כל תכונה מורחבת או ACL. בדוח נפריד בין תוכן שהועתק, זהות קישורים ששומרה, הרשאות ותכונות שנכשלו, כדי שלא להציג שחזור חלקי כשחזור מלא.

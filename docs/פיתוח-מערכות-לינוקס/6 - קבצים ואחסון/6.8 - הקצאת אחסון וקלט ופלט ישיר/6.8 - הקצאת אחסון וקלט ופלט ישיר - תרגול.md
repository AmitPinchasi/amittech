# תרגול גודל לוגי ואחסון מוקצה

צרו sparse file והשוו גודל לוגי ובלוקים מוקצים לפני כתיבה, אחרי כתיבה ואחרי סנכרון. העתיקו אותו פעם כזרם בייטים ופעם בכלי ששומר חורים, ותעדו את ההבדל בלי להניח שכל filesystem יתנהג זהה.

תכננו באפר מיושר עבור ניסוי `O_DIRECT`, כולל חישוב גודל, בעלות ושחרור. כתבו איך תגלו את דרישות היישור ומה תעשו כאשר הממשק או filesystem אינם תומכים בבקשה.

הסבירו מדוע הצלחת כתיבה ישירה אינה אישור עמידות, ומדוע השוואת ביצועים חייבת להשתמש באותו גבול אישור בשתי הגרסאות.

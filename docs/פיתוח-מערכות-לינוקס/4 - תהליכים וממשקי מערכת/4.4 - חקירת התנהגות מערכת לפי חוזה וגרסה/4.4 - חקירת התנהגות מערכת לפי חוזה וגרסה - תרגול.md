# תרגול גילוי יכולות

הרחיבו את תוכנית הגילוי כך שתדפיס את קוד השגיאה ואת ההקשר שלה בלי לאבד את השגיאה המקורית. הפרידו בין יכולת זמינה, פעולה שאינה זמינה ושגיאה אחרת. אל תשלבו את כל המצבים תחת ערך בוליאני יחיד.

הריצו את הבינארי ישירות תחת `strace` ושמרו את הקריאה הרלוונטית. השוו את התוצאה בתוך סביבת בידוד אם קיימת אצלכם, אבל אל תשנו מדיניות אבטחה של המחשב כדי לכפות הצלחה.

תכננו שני לקוחות של הגילוי: כלי שמציג תהליכים וכלי שמתחייב לאותת לתהליך המקורי בלבד. כתבו עבור כל אחד מדיניות fallback מנומקת והסבירו איזו הבטחה משתנה.

# תרגול זהות מתארים

הרחיבו את התוכנית כך שאחרי שתי הקריאות הראשונות תבצעו `seek` דרך אחד המתארים המשוכפלים ותקראו דרך האחר. השוו לפתיחה העצמאית, ותעדו את המיקום שנראה בכל מסלול.

כתבו פונקציה שמקבלת `BorrowedFd` לצורך אבחון ואינה סוגרת אותו, ופונקציה שמקבלת `OwnedFd` ומעבירה אותו לבעלים חדש. הציגו בחתימות את ההבדל בין השאלה להעברה.

ציירו רצף שבו מספר fd נסגר ומוקצה מחדש. הסבירו מדוע בדיקת `fd >= 0` אינה בדיקת זהות או זמן חיים, ומדוע עטיפה שנוצרה פעמיים מאותו מספר מפרה את חוזה הבעלות גם אם ההרצה הקצרה לא קרסה.

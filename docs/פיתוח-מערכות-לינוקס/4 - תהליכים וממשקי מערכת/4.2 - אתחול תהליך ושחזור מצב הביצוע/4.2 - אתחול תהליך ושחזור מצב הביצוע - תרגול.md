# תרגול אתחול ומחסניות

בנו את תוכנית הפאניקה עם נתוני דיבוג בשתי רמות אופטימיזציה, ושמרו את המחסנית מכל הרצה. הסירו את `inline(never)` והשוו שוב. ציינו אילו שמות מופיעים ואילו מסגרות עשויות להיות תיאור לוגי של inlining.

בדקו את `PT_INTERP`, את המיפויים ואת ה־build ID של תוכנית האתחול. הסבירו מדוע קובץ הספרייה והכתובת שבה נטען הם שני פרטי מידע שונים, ומדוע ASLR מקשה על השוואת כתובות מוחלטות.

העבירו לתוכנית ארגומנט שאינו UTF-8 באמצעות תסריט Python קטן. השוו בין `args_os` לבין שינוי הקוד ל־`args`, ותעדו את התוצאה בלי להניח שכל ארגומנט הוא מחרוזת תקינה.

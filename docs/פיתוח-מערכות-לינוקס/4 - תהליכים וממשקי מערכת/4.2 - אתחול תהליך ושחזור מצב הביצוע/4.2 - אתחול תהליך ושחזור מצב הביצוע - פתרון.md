# פתרון אתחול ומחסניות

הפקודות הבאות בונות שתי גרסאות עם מידע דיבוג, ולכן ההבדל אינו פשוט קיומם או היעדרם של שמות.

```bash
rustc --edition=2024 -g -C opt-level=0 panic.rs -o panic-debug
rustc --edition=2024 -g -C opt-level=3 panic.rs -o panic-release
RUST_BACKTRACE=1 ./panic-debug
RUST_BACKTRACE=1 ./panic-release
readelf -n panic-release
```

התסריט הבא מיועד ללינוקס ויוצר ארגומנט עם בייט שאינו רצף UTF-8 תקין. הנתיב לבינארי צריך להתאים לשם שבו בניתם אותו.

```python
import os
os.execv(b"./startup", [b"./startup", b"bad-\xff"])
```

הטיפוס `OsString` שומר את ייצוג מערכת ההפעלה, ואילו הממשק שמחזיר `String` דורש UTF-8. בתחקיר מחסנית נשתמש ב־build ID כדי להתאים את הסמלים, ובבסיס המיפוי כדי לתרגם כתובת runtime למיקום בתוך האובייקט. הופעת שורה בדוח אינה מבטיחה שהמשתנים של אותה שורה עדיין קיימים בצורה שניתנת לקריאה.

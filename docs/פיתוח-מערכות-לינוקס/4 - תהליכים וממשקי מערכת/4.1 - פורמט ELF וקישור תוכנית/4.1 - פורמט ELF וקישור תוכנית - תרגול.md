# תרגול קישור וטעינה

בנו את הדוגמה הסטטית ואת הדוגמה הדינמית, ושמרו עבור כל אחת רשימת `NEEDED`, טבלת program headers ומיקום הסימבול `scale_value`. הסבירו מדוע הוספת הספרייה הסטטית אינה מחייבת היעדר interpreter בבינארי.

צרו שתי תקלות נפרדות: ספרייה חסרה בזמן קישור וספרייה חסרה בזמן טעינה. תעדו איזה כלי נכשל בכל מקרה ואיזה שינוי בסביבת החיפוש פותר את התקלה. אל תתקנו את שתיהן באמצעות העתקת ספריות אקראית לתיקיית מערכת.

הוסיפו פונקציה פנימית לספרייה והסתירו אותה מהממשק הדינמי. בדקו את ההבדל בין `readelf -s` לבין `readelf --dyn-syms` והסבירו למה שם שנראה בקובץ אינו בהכרח API ציבורי.

## תרגול לקוח שמנסה להפר את החלוקה

הרחיבו את הבדיקות של split_checked לחיתוך באפס, בסוף ומעבר לסוף. בדקו גם מערך של יחידות `()` כדי לא להסתמך על כתובות שונות לכל איבר.

כתבו בנפרד דוגמה שאמורה להידחות: שמרו את שתי הפרוסות, שנו את values המקורי ואז השתמשו שוב באחת מהן. הסבירו איזה חלק בחתימה מונע את השימוש.

בדקו את Borrowed עם String והראו שאפשר לשנות אותה דרך get_mut בלי להוסיף constructor ממספר גולמי.

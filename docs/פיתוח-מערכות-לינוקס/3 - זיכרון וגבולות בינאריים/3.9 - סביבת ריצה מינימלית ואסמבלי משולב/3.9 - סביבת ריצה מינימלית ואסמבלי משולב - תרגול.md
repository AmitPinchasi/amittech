# תרגול סביבת ריצה מינימלית

הרחיבו את `write_once` כך שתקבל גם מספר מתאר. כתבו את ההודעה למתאר `2`, והריצו את התוכנית עם הפניית הפלט הרגיל לקובץ כדי לוודא שהבחנתם בין שני המתארים.

שנו את נקודת הכניסה כך שהשלמה מלאה מחזירה קוד `7`, וכתבו פקודת shell שמציגה את קוד הסיום. בדקו בפלט `strace` אם התוצאה עוברת דרך libc או מתקבלת ישירות מקריאת המערכת שלכם.

נתחו מדוע הוספת `options(nomem)` לפעולת הכתיבה מפרה את החוזה. הסבירו גם מדוע אסור לקחת את קוד הכניסה הזה כפי שהוא ל־ARM64, ומדוע ערך שלילי מהקרנל אינו מספר הבייטים שנכתבו.

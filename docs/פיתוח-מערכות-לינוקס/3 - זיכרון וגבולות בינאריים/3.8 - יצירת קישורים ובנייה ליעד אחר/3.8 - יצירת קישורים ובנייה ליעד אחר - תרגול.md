# תרגול בנייה וקישור

הרחיבו את ספריית `native_probe` בפונקציה שמחזירה `sizeof(struct probe_result)` ובפונקציה שמחזירה את המיקום של `value`. כתבו בדיקה בצד ראסט שמשווה מול הפריסה שנוצרה ב־bindgen.

שנו את סדר השדות בכותרת והריצו שוב את הבדיקות. ודאו שהכותרת הפעילה בנייה מחדש, ואז תעדו אילו קבצים נבנו ואילו נשמרו מהמטמון. נסו להסיר זמנית את הגדרת `cc::Build` והסבירו מדוע יצירת הכרזות מוצלחת אינה מספיקה לקישור.

הכינו דוח בנייה ליעד נוסף גם אם אין לכם עדיין סביבת הרצה שלו. רשמו בנפרד את target של ראסט, קומפיילר הסי, linker, sysroot והארכיטקטורה של האובייקט שנוצר. אל תציגו בדיקת קומפילציה כבדיקת הרצה.

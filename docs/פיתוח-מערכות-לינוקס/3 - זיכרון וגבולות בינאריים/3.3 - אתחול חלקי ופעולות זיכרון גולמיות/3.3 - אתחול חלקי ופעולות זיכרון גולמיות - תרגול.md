## תרגול ניקוי של קידומת מאותחלת

הוסיפו למבנה Buffer מההרצאה מתודה clear שמשמידה את כל הערכים ומחזירה אותו למצב ריק. השתמשו ב־pop כך שלא יהיה צורך ב־unsafe חדש.

הגדירו טיפוס Tracked שמחזיק מזהה ומונה השמדות משותף מסוג Rc של Cell. הכניסו שלושה ערכים, הוציאו אחד, הפעילו clear והשמידו לבסוף את הערך שהוצא. בדקו מתי המונה גדל ומי הבעלים של כל ערך בכל שלב.

הסבירו מדוע אין לקרוא assume_init_read פעמיים מאותו תא בלי להחזיר אליו בעלות חדשה.

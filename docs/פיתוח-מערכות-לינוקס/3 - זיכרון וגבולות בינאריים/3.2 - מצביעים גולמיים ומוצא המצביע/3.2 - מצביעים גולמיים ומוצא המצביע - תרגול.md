## תרגול הוכחת טווח לפני קריאה גולמית

כתבו `read_at(values: &[u32], index: usize) -> Option<u32>` באמצעות as_ptr, add ו־read. בדקו את הגבול לפני כל פעולת unsafe, ותעדו מדוע הפרוסה מספקת חיי נתון, יישור ואתחול.

השוו למימוש עם `get(index).copied()` על קלט ריק, אינדקס אפס, האיבר האחרון ו־usize::MAX. הסבירו מדוע אסור לחשב כתובת לא חוקית באמצעות add לפני שמגלים שהאינדקס מחוץ לטווח.

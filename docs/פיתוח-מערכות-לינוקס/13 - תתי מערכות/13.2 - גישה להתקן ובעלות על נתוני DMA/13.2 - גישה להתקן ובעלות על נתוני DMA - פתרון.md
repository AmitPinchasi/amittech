# פתרון גישה להתקן ובעלות על נתונים

## פתרון ראשון

קריאה ל־`buffer.bytes()` אחרי `submit` נכשלת מפני שהערך הועבר. המהדר מונע גישה דרך הבעלים הקודם, אך אינו מכיר את חוזה העצירה של התקן אמיתי, את משמעות האוגרים או את תחזוקת המטמון הנדרשת. במימוש חומרה נצטרך מעטפת בלתי בטוחה שהוכחתה כוללת את החובות האלה.

## פתרון שני

נקצה באפר מתאים, נמפה בכיוון כתיבה מההתקן, נבדוק כשל מיפוי ונגיש את הכתובת שהוחזרה. לאחר השלמה מוכחת נבצע סנכרון למעבד אם נשמר המיפוי, או נבטל מיפוי בהתאם למסלול שנבחר, ורק אז נקרא את הנתונים. בפסק זמן נעצור את הגשות העבודה ונפעיל מנגנון עצירה מאומת של ההתקן לפני ביטול המיפוי. עצם חלוף הזמן אינו משנה בעלות.

## פתרון שלישי

קוהרנטיות עוסקת בנראות תוכן דרך מטמונים ואינה הופכת כמה כתיבות לעסקה אחת. נכתוב את שדות התיאור, נבצע את מחסום הפרסום המתאים לממשק ולהתקן ואז נכתוב את ביט הבעלות. אם נדרש גם להבטיח הגעה של כתיבה לאוגר, נטפל בכך לפי חוזה האפיק בנפרד.

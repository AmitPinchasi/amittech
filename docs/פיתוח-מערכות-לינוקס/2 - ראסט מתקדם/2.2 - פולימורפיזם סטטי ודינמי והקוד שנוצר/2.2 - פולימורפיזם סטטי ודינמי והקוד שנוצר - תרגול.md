## תרגול אוסף מקורות דינמי

הגדירו trait בשם Metric עם מתודה שמחזירה u64. ממשו אותו לטיפוס Constant שמחזיק מספר ולטיפוס Length שמחזיק String ומחזיר את מספר הבייטים שלה.

בנו Vec של Box של אובייקטי trait והדפיסו את הסכום. כתבו גם פונקציה גנרית שמקבלת פרוסה של אותו טיפוס Metric. הסבירו מדוע הפונקציה הגנרית אינה מקבלת ישירות מערך שמכיל Constant ו־Length כערכים שונים.

הוסיפו לתכונה מתודה גנרית, ראו את השגיאה בשימוש ב־dyn, ואז הגבילו אותה ל־Self: Sized. הסבירו איזו פעולה נעלמה מן הממשק הדינמי.

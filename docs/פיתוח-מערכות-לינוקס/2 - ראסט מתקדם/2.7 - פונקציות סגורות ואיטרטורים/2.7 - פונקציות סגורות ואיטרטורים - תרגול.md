## תרגול pipeline עם בעלות מפורשת

כתבו פונקציה שמקבלת פרוסת String ומחזירה Vec של הפניות למחרוזות שאורכן לפחות ארבעה בייטים. כתבו פונקציה נוספת שמחזירה Vec של String עצמאיות לאותם איברים.

הוסיפו inspect שמדפיס כל איבר שנבדק והגבילו את הצריכה לשתי תוצאות. הסבירו מדוע מספר האיברים שנבדקו אינו חייב להיות שתיים.

כתבו closure בבעלות שמשתמשת ב־move אך עדיין ניתנת לקריאה פעמיים. כתבו בנפרד closure שמוציאה את הערך מן הסביבה וניתנת לקריאה פעם אחת.

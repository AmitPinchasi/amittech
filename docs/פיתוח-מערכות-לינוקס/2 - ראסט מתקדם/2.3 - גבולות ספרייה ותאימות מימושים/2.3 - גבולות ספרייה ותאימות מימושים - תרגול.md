## תרגול טיפוס בעל משמעות ולא רק שם

הגדירו טיפוס בשם Port שמחזיק u16 פרטי. ספקו constructor שמקבל u32 ומקבל רק את הטווח 1 עד 65535. ממשו Display עבור Port, והוסיפו מתודה שמחזירה את המספר לאחר האימות.

השוו את הטיפוס להגדרה `type PortAlias = u16`. הסבירו מה המעטפת מונעת שה־alias אינו מונע. כתבו בדיקות לקצוות הטווח ולערך שלא ניתן לייצג ב־u16.

הוסיפו ניסיון למימוש Display ישירות עבור u16 בקובץ נפרד, וקראו את האבחון. אין להכניס את הקובץ הכושל ליעד הבנייה התקין.

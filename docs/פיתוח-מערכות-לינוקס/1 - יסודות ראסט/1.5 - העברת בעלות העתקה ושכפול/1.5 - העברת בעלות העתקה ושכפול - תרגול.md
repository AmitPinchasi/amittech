## תרגול העברת בקשה והחזרת תוצאה

הגדירו מבנה Request עם שם String ועדיפות u8. כתבו פונקציה `normalize` שמקבלת Request בבעלות, מוסיפה לשם את הסיומת `.job` ומחזירה את הבקשה המעודכנת.

כתבו קריאה שמדגימה שהמשתנה המקורי אינו זמין אחרי ההעברה, ואז תקנו את הקוד באמצעות שימוש בערך המוחזר. כתבו גרסה נוספת ששומרת גם עותק מקורי, והסבירו היכן בדיוק מתרחש השכפול.

הוסיפו ניסיון לממש Copy למבנה וקראו את שגיאת המהדר. הסבירו מדוע העובדה שהמבנה קטן בתיאור שלו אינה מתירה העתקת בעלות על ההקצאה.

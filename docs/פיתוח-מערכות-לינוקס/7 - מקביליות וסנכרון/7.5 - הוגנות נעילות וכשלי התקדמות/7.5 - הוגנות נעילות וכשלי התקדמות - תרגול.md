# תרגול סדרי נעילה

כתבו גרסה פגומה של העברה שנועלת מקור ואז יעד, והשתמשו במחסום בדיקה כדי לכפות ששני עובדים יחזיקו את הנעילה הראשונה לפני הניסיון השני. הריצו אותה תחת timeout בתהליך נפרד, כדי שמבחן התקלה לא יתקע את כל סביבת הבדיקות.

השוו לגרסה המסודרת, והוסיפו העברות בין שלושה חשבונות. בדקו שהסכום הכולל נשמר גם כאשר פעולה נדחית בגלל חוסר יתרה או overflow.

תכננו callback שנקרא בזמן החזקת נעילה ויוצר כניסה חוזרת. הציעו שינוי API שמוציא את הקריאה מהנעילה, וציינו איך מטפלים במצב שהשתנה בזמן ה־callback.

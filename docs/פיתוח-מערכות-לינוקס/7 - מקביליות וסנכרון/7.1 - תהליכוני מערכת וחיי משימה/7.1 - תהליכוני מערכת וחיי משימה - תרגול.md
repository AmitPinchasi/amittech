# תרגול חלוקת עבודה מושאלת

חלקו `Vec<u64>` לחלקים באמצעות `chunks_mut` וחשבו בכל חלק פעולה שאינה תלויה בחלקים האחרים. בדקו מספר איברים שאינו מתחלק בגודל החלק ומאגר ריק.

כתבו גרסה שמחזירה מכל עובד תוצאה קטנה ומצרפת אותה אחרי `join`. הזריקו פאניקה בעובד אחד והגדירו כיצד הפונקציה הראשית מדווחת עליה בלי להציג תוצאה חלקית כהצלחה מלאה.

השוו בין הפלת `JoinHandle` לבין המתנה עליו. הסבירו מי ממשיך להחזיק את הנתונים שהועברו לעובד ומה חסר כדי לבקש ממנו לעצור.

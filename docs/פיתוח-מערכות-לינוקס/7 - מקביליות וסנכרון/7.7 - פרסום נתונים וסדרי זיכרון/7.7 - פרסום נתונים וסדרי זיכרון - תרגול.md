# תרגול הוכחת פרסום

ציירו את סדר האירועים בדוגמת Packet וסמנו איזה load רואה את ה־store שמפרסם את הנתון. הסבירו למה ה־load של payload יכול להישאר Relaxed תחת ההנחות של הדוגמה.

נתחו ניסיון להשתמש שוב באותו דגל באמצעות כתיבת false ואז true עבור הודעה חדשה. ציינו מה חסר כדי לוודא שהקורא סיים עם ההודעה הישנה ושלא קרא מצב מעורב.

כתבו מבחן מודל עתידי לשני תהליכונים שכותבים וקוראים שני אטומים. הגדירו איזו תוצאה מותרת בסדר החלש ואיזו צריכה להידחות כאשר כל הפעולות הן SeqCst.

# תרגול המתנה וסגירה

החליפו את `Option` במצב שמכיל תוצאה אופציונלית ודגל `closed`. הצרכן צריך להמתין רק כל עוד אין תוצאה והמצב אינו סגור. הגדירו מה הוא מחזיר כאשר הערוץ נסגר בלי תוצאה.

הוסיפו קריאה ל־`notify_all` בלי שינוי המצב ובדקו שהצרכן אינו מחזיר תוצאה מדומה. כתבו גם גרסה פגומה עם `if` והסבירו את רצף האירועים שבו ההנחה שלה נשברת.

הזריקו פאניקה אחרי שינוי חלקי של מצב מוגן. כתבו מדיניות poison שמחזירה כשל או מתקנת אינווריאנט מוגדר, במקום לקרוא תמיד `into_inner` ולהמשיך.

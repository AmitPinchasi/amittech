# תרגול חקירה שיטתית של סדרי ביצוע

הריצו את מודל הפרסום עם release/acquire ועם הגרסה החלשה. שמרו את דוגמת הנגד והסבירו אותה באמצעות האירועים, בלי להסתפק בשם השגיאה של הכלי.

כתבו מודל קטן לתור בעל קיבולת אחת עם מפיק וצרכן. בדקו פרסום, ריק, מלא וסגירה. הגבילו את מספר הפעולות כדי שאפשר יהיה להבין כל סדר שנמצא.

תכננו מדידת מנוע עבודה עם מספר workers משתנה. שמרו את אותה כמות עבודה והפרידו בין משימות CPU למשימות חסומות. הציגו latency ו־throughput לצד מדד נכונות של התוצאה.

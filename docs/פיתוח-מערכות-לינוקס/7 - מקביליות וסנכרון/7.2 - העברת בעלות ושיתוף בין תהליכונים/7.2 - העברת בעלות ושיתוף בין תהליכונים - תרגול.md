# תרגול חוזי העברה ושיתוף

כתבו פונקציות בדיקה גנריות שדורשות `Send` ו־`Sync`, ובדקו מולן `String`, `Rc<String>`, `Arc<String>` ו־`Arc<RefCell<String>>`. שמרו שימושים שאמורים להיכשל בקבצים נפרדים ותעדו את הסיבה.

צרו טיפוס ידית לימודי עם marker שמונע העברה בין תהליכונים. הסבירו איזה חוזה חיצוני יכול להצדיק את ההגבלה, ואילו ראיות יידרשו לפני הוספת מימוש `unsafe` ידני.

בנו ניסוי שמבצע הרבה שכפולי `Arc` והשוו להעברת בעלות אחת לעובד. ציינו אילו פעולות לוגיות נשארו זהות ואילו עלויות הסרתם מהלולאה.

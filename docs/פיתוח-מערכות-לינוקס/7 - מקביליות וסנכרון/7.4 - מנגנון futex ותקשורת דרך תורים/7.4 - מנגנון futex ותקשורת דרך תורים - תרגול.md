# תרגול לחץ חוזר ובעלות על הודעה

שנו את הקיבולת בין אפס, אחד וכמה פריטים. מדדו מתי המפיק מתקדם ומה קורה כאשר הצרכן איטי. הסבירו את החוזה של ערוץ בקיבולת אפס לעומת תור ששומר פריט אחד.

כתבו שליחה לא חוסמת שמחזירה למשתמש את ההודעה בכל כשל. בדקו תור מלא ומקבל שנסגר, וודאו שאין clone מיותר שמסתיר מי הבעלים.

ציירו רצף שבו דגל ביטול נבדק לפני שליחה חסומה אבל אינו יכול להעיר אותה. הציעו איזה מצב ו־notification נדרשים בתור כדי לסגור את החלון.

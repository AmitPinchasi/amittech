# תרגול חבילת שירות

הכינו חבילה לפורמט ההפצה שבחרתם, עם binary, unit ותצורה. הגדירו אילו קבצים שייכים לחבילה ואילו נשארים בבעלות המשתמש. בדקו upgrade שאינו מוחק יומן קיים ו־uninstall שאינו מפר את מדיניות שימור הנתונים.

הריצו את החבילה בשתי סביבות יעד ורשמו kernel, libc, systemd וארכיטקטורה. בחרו יכולת אחת עם fallback והראו שההתנהגות נשמרת, או שהשירות מסרב לפעול עם שגיאה ברורה כשהיא חיונית.

בדקו ש־TimeoutStopSec גדול מגבול ה־drain המתוכנן בתנאי המעבדה, ושעבודה שלא הסתיימה לפני סיום כפוי חוזרת למצב מוגדר אחרי restart. אין להפוך את הגדלת הזמן לאינסוף לתיקון של deadlock.

# תרגול הגירה שנקטעת

הוסיפו נקודות עצירה אחרי כתיבת הדור, אחרי sync שלו, אחרי יצירת manifest זמני, אחרי rename ואחרי directory sync. הריצו על תיקייה חדשה לכל ניסוי וכתבו מה אמור להיבחר בהפעלה הבאה.

כתבו parser ל־manifest שמאפשר רק שם דור יחיד מתוך אותה תיקייה, ודוחה נתיב מוחלט, `..`, תווי אפס ושורות נוספות. הוסיפו בדיקת schema של הדור לפני הצגתו כפעיל.

תכננו rollback כאשר גרסה 2 כבר קיבלה עשר כתיבות חדשות. הציגו במפורש אם אתם מבצעים המרה לאחור, חוסמים downgrade או משחזרים backup תוך אובדן מידע שמדווח למפעיל.

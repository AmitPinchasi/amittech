# תרגול בקשות חוזרות

הוסיפו למודל lookup שמחזיר תוצאה או Unknown, ומגבלה של 100 רשומות. הגדירו מה קורה לבקשה חדשה כשהמגבלה מלאה, ולבקשה חוזרת קיימת באותו מצב. בדקו conflict גם אחרי שהמפה מלאה.

כתבו טבלת כשלים עבור קריסה לפני append, אחרי append ולפני fsync, אחרי fsync ולפני reply ואחרי reply. ציינו מה יודע השירות אחרי recovery ומה רשאי הלקוח להסיק בכל נקודה.

הציעו מדיניות לפעולה שמבצעת השפעה במערכת חיצונית, למשל כתיבה לשירות אחר. הסבירו למה deduplication ביומן המקומי אינו מספיק לבדו להבטחת בדיוק־פעם מעבר לגבול הזה.

# תרגול שחזור בנייה

בנו את אותו commit בשתי תיקיות בעלות נתיבים שונים, עם lockfile ו־toolchain זהים. השוו hash של binary ושל debug artifacts, ותעדו כל הבדל. אל תסירו debug information רק כדי להסתיר הבדל בלי להסביר את מחיר האבחון.

בצעו vendor לתלויות בפרויקט מעבדה, שלבו את configuration הקיים ובנו במצב frozen עם רשת חסומה. הוסיפו build.rs קטן שמנסה לקרוא משתנה סביבה והראו כיצד מידע לא מתועד משנה את התוצר.

כתבו רשומת החלטה עבור תלות חדשה: צורך, חלופות, features, מקור, רישיון, תחזוקה ותוכנית עדכון. נדרשת הבחנה בין pinning שמאפשר שחזור לבין הקפאה שמונעת תיקוני אבטחה לאורך זמן.

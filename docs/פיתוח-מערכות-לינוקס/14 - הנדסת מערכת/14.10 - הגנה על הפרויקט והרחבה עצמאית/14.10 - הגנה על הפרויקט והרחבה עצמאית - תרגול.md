# תרגול הגנה על מערכת

בחרו בקשה אחת מן הפרויקט והכינו הסבר בן עשר דקות שעובר מן API עד syscall ומסלול kernel רלוונטי. לכל pointer, fd ו־buffer במסלול ציינו בעלים, תקופת חיים ואירוע שחרור. הציגו גם trace וגם קטע מקור שתומכים בהסבר.

החליפו עם עמית תקלה אחת שאינה מתועדת מראש. דרשו ממנו לנסח השערה, לבדוק אותה ולתקן את החוזה שנשבר. ההגשה תכלול ניסוי שנכשל לפני התיקון ועובר אחריו, ולא רק diff של שורה.

ממשו הרחבה עצמאית קטנה עם חוזה חדש וברור. הציגו אילו בדיקות ישנות ממשיכות לעבור ואילו בדיקות נוספו כדי להגן על ההבטחה החדשה.

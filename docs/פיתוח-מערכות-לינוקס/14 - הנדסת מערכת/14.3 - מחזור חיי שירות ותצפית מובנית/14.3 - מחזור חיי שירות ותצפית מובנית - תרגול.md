# תרגול סגירה ותצורה

הוסיפו למודל generation של תצורה, והגדירו reload שנכשל בלי לשנות אף שדה פעיל. בדקו reload בזמן Ready ובזמן Draining והחליטו אם שניהם נתמכים.

בנו בדיקת interleaving שבה admission ו־drain מתחרים. נדרשת הוכחה שבקשה או נדחית או נספרת לפני שהמערכת יכולה להגיע ל־Stopped. הסבירו איזה lock או מבנה בעלות מספק את ההכרעה.

כתבו רשימת אירועים עבור shutdown בזמן בקשה עמידה אחת ובקשה שטרם התקבלה. הגדירו מה יודפס ומה יישאר לשחזור. הוסיפו בדיקה שמוודאת שאין request ID בתוך labels של metrics בעלי cardinality לא מוגבלת.

# פרויקט סביבת הרצת משימות

נרחיב אחרי פרק 4 את מפקח התהליכים למריץ pipelines. הלקוח בוחר אם צריך PTY או pipes רגילים, והמפקח מחזיר פלט, exit status ומצב timeout בלי להשאיר zombies.

ההרחבה כוללת כמה שלבים בצינור, exec failure בערוץ מפורש, תקרת מתארים ומגבלת פלט. ביטול מטפל בקבוצת התהליכים לפי החוזה, תוך הכרה בכך שprocess group לבדו אינו גבול אבטחה מול ילד שמורשה לצאת ממנו.

בודקים כשל ביצירת pipe, כשל spawn בשלב אמצעי, child שאינו קורא stdin וchild שמשאיר descendent עם פלט פתוח. התוצאה אינה תלויה בהמתנה עיוורת לEOF ללא deadline.

מגישים מפת descriptors לפני ואחרי exec, ורשימת הילדים שנקצרו בכל מסלול. שער המעבר דורש אפס zombies ומתארים שנותרו ללא בעלים בתוך חוזה המפקח.

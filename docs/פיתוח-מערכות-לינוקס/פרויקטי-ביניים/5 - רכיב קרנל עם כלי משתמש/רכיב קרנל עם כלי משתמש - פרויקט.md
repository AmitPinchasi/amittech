# פרויקט רכיב קרנל עם כלי משתמש

נרחיב אחרי פרק 12 את רכיב תור האירועים עם סוג בקשה אסינכרוני חדש וגרסת ABI נוספת. הלקוח בראסט צריך לעבוד גם מול גרסת הרכיב הישנה לפי מטריצת תאימות מפורשת.

ההרחבה מוסיפה ביטול בזמן ניתוק או סגירת fd, ותחרות בין worker לבין cancel על סיום בקשה. כל request חייב להגיע להכרעה אחת, וכל context נשאר חי עד שסיימו להשתמש בו.

מגישים KUnit או בדיקות מתאימות למנגנון, לקוח עומס וחקירה שמחברת פלט משתמש למסלול מקור בקרנל. נועלים kernel commit וגרסאות כלים, ומריצים רק בסביבת הקרנל המבודדת של הקורס.

# תרגול מקצים וערמות משתמש

הריצו את ניסוי ה־heap והשוו סדר שחרור זוגי־אי־זוגי לסדר יצירה הפוך. מדדו זמן והיקף משאבים תחת אותו עומס, בלי להניח שהבדל קטן בריצה אחת משמעותי.

כתבו עטיפת RAII ל־heap פרטי ולבלוק שמוחזק בו. הגדירו מדוע ה־heap חייב לחיות יותר מהבלוק ומהאובייקט שבנוי עליו.

הוסיפו טיפוס עם destructor שמגדיל מונה, ובנו אותו באמצעות construct_at בתוך בלוק. הוכיחו ש־HeapDestroy לבדה אינה קוראת ל־destructor.

תכננו עומס שמשלב שני גדלי בלוקים ושני משכי חיים. הסבירו איזה סוג fragmentation אתם מנסים לבדוק ובאיזו שכבת מדידה.

השוו arena מוגבלת למקצה כללי עבור בקשה שמייצרת עשרות אובייקטים ונגמרת כמקשה אחת. כללו גם כשל באמצע הבקשה.

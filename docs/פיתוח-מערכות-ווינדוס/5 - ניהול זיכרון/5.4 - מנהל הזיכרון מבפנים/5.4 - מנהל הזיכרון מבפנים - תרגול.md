# תרגול מנהל הזיכרון מבפנים

הפעילו את ניסוי העצירות ושמרו תצפית לכל שלב: reserve, commit, touch, decommit ו־release. הפרידו מידע שנאסף ב־user mode ממידע שדורש kernel debugging.

בנו טבלה עם שלוש עמודות: VAD, PTE ו־PFN. עבור כל עמודה ציינו את היחידה, סוג השאלה שהיא עונה עליה ודוגמה למסקנה שאסור להסיק ממנה.

ביעד VM מתאים חקרו כתובת אחת לפני ואחרי נגיעה. השתמשו רק בכתובות מההרצה ובסמלים תואמים. אם אין יעד מתאים, הגישו תכנון ובדיקות user mode בלי פלט פנימי מומצא.

השוו תיאור של טיפוס פנימי בשני builds זמינים. בחרו שינוי אחד והסבירו מדוע אינו מחייב שינוי בקוד שמשתמש ב־VirtualAlloc לפי החוזה.

נתחו טענה שמספר ה־references של PFN שווה למספר מצביעי C++ שמכילים את אותה כתובת.

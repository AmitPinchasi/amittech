# תרגול הגנות וחיי מיפוי

הריצו את ניסוי read only והוסיפו כתיבה מכוונת בזמן שההגנה אינה מאפשרת אותה. תעדו בדיבאגר את כתובת התקלה, סוג הגישה והגנת הדף. השינוי נשאר בתוכנית המעבדה בלבד.

הריצו את ניסוי ה־guard ב־MSVC. בדקו את ההגנה לפני ואחרי הגישה הראשונה באמצעות VirtualQuery, והסבירו מדוע הגישה השנייה אינה בהכרח נכשלת.

תכננו עטיפה שמשנה זמנית הגנה של כמה דפים. הגדירו מה קורה אם ההגנות המקוריות שונות, וכיצד נשמר מצב בכל כשל.

בנו אובייקט עם destructor בתוך דף שהוקצה ב־VirtualAlloc. הציגו סדר נכון של construct, שימוש, destroy ו־release, והסבירו למה MEM_RELEASE אינו קריאת destructor.

השוו PAGE_GUARD, PAGE_NOACCESS ו־read only לצורך זיהוי גלישה מ־buffer.

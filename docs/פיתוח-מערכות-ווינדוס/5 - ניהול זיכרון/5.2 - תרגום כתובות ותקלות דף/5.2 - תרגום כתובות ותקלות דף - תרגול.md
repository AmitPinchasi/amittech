# תרגול תרגום כתובות ותקלות דף

הריצו את הניסוי עם קריאה ראשונה ועם כתיבה ראשונה, ושמרו את ספירת הדפים התושבים. אל תגדילו את הטווח עד ליצירת לחץ מערכת בלתי מוגבל.

הוסיפו מדידת זמן לסריקה ראשונה ולסריקה שנייה. שמרו את התוצאה הנקראת כדי שהמהדר לא יסלק את הסריקה, ותעדו flags ורזולוציית שעון.

הסבירו שלושה מסלולים שונים: TLB miss שנפתר בטבלאות, demand-zero fault ו־hard fault של קובץ. ציינו מי משתתף בכל מסלול.

כתבו מדוע מונה PageFaultCount של process אינו מאפשר להסיק לבדו כמה קריאות דיסק התרחשו.

אם קיימת VM עם kernel debugger, חקרו PTE של כתובת הניסוי לפני ואחרי נגיעה. אם אינה קיימת, הגישו את תכנון הניסוי ואת המגבלה בלי להמציא פלט.

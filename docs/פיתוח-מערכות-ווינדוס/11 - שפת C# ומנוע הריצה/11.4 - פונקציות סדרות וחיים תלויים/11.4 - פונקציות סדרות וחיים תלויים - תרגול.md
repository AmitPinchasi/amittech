# תרגול חיי סגירות וסדרות

כתבו iterator שמחזיר שורות מתוך TextReader ומדפיס הודעה ב־finally. הגדירו שה־iterator אינו הבעלים של ה־reader, וצאו מלולאת foreach אחרי שורה אחת. ודאו שה־finally מתבצע בלי לסגור את ה־reader של הקורא.

כתבו Publisher ו־Subscriber שמחזיק מערך של מיליון byte-ים. הוסיפו מונה קריאות והראו שניתוק באמצעות Dispose מפסיק קריאות עתידיות בחוזה חד־תהליכי. דרשו שקריאת Dispose שנייה תהיה חסרת השפעה. ציירו את מסלול ה־references לפני הניתוק ואחריו.

תקנו את לולאת ה־closures מן ההרצאה כך שתחזיר 0, 1 ו־2. הסבירו למה ToArray של רשימת ה־delegates לבדה אינו מתקן את המשתנה שנלכד.

# תרגול תחילת תוכנית והטוען

הריצו את דוגמת האתחול עם breakpoint ב־`initialize_value`. שמרו את שרשרת הקריאות, את entry RVA ואת המקום שבו main נקרא. הפרידו בין עובדה שנצפתה לבין הנחה לגבי runtime אחר.

הרחיבו את הלקוח הדינמי מהשיעור הקודם לטעינת `context.dll`, פתרון create ו־destroy, יצירת context והשמדתו לפני unloading. בדקו קיבולת אפס, קיבולת מותרת וקיבולת מעל המגבלה.

נתחו את מעגל ההמתנה שבו DllMain יוצר thread וממתין שהוא יאותת. שרטטו שני threads ואת הנעילה שמונעת התקדמות. אין צורך להכניס deadlock למחשב העבודה.

הציעו שינוי בממשק שבו הספרייה הייתה בעבר קוראת קובץ תצורה בבנאי גלובלי. הגדירו מי מספק את התצורה, באיזה שלב מחזירים שגיאה ומי מנקה מצב שנוצר חלקית.

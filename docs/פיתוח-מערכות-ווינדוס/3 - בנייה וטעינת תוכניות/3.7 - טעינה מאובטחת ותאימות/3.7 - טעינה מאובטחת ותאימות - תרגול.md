# תרגול טעינה מאובטחת ותאימות

בנו ספריית engine שתלויה ב־helper, והפעילו את מדיניות החיפוש מההרצאה. בדקו שני מצבים: שתי הספריות באותה תיקייה, ו־helper בתיקיית עבודה אחרת. רשמו את הנתיבים שנבדקו ואת קוד הכשל.

הוסיפו ל־calc יכולת אופציונלית בשם `scale_extended`. בנו גרסה שבה היא חסרה, וכתבו לקוח שמשתמש בפעולה הישנה כאשר החיפוש נכשל. שמרו משמעות עקבית לתוצאה או תעדו את ההבדל במפורש.

שלבו את ה־manifest בתוצר ובדקו אותו באמצעות כלי ה־SDK. הסבירו את ההבדל בין `asInvoker`, הצהרת supportedOS והגדרת `_WIN32_WINNT`.

נתחו ספרייה שמשנה את current directory כדי להקל על טעינת תלויות. הסבירו איך השינוי יכול להשפיע על threads אחרים ועל פתיחת קבצים שאינה קשורה לטעינה.

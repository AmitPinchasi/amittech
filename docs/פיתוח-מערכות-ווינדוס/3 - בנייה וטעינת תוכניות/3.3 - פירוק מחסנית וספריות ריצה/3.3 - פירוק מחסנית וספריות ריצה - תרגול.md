# תרגול פירוק מחסנית וספריות ריצה

הריצו את תוכנית הסמנים ושרטטו את סדר הבנייה וההשמדה. הוסיפו ל־`outer` אובייקט נוסף אחרי הקריאה ל־`inner`, והסבירו מדוע הוא אינו מושמד במסלול הכשל.

השוו call stack ואסמבלי ב־`/Od` וב־`/O2`. שמרו את שני ה־PDBים יחד עם ה־images המתאימים. מצאו מסגרת אחת שבה RSP שונה מנקודת הכניסה, והסבירו איזה מידע צריך כדי לשחזר את הקורא.

תכננו ממשק C לספרייה שמחזירה מערך bytes שנוצר אצלה. כתבו את חוזה הבעלות, פעולת השחרור ותרגום החריגות. הציעו ממשק חלופי שבו הלקוח מספק אחסון.

נתחו את הטענה הבאה: אם catch אינו תופס access violation, צריך לשנות flags עד שיתפוס ולהמשיך. הסבירו איזה מידע הולך לאיבוד ולמה המשך ביצוע אינו הוכחת התאוששות.

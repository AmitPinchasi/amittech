# תרגול סמלים ואופטימיזציה

בנו את שתי גרסאות הדוגמה ועצרו בחריגה המכוונת. שמרו call stack, מצב טעינת symbols ואסמבלי של `analyze`. בדקו אם `transform` קיימת כקריאה פיזית בכל גרסה.

נסו לצפות ב־total לפני ההדפסה ואחריה. תעדו מתי הערך זמין ומתי אינו זמין, בלי לשנות אופטימיזציה כדי להסתיר את השאלה.

העתיקו את ה־PDB לתיקיית ארכיון, בנו שינוי קטן במקור ובדקו כיצד הדיבאגר מגיב לניסיון להשתמש בסמלים שאינם תואמים. אין לכפות טעינה של symbols שגויים לצורך מסקנה.

פצלו את transform לקובץ נוסף והשוו בנייה רגילה לבנייה עם `/GL` ו־`/LTCG`. תעדו מה השתנה בפועל ומה נשאר תלוי בגרסת הכלים.

תכננו חבילת תחקיר לגרסה ישנה: רשמו איזה מידע חייב להישמר ומי מסוגל לשחזר ממנו את החקירה.

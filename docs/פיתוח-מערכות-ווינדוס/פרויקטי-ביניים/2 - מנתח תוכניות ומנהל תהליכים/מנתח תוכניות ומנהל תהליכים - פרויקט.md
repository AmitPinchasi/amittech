# פרויקט מנתח תוכניות ומנהל תהליכים

נחבר אחרי פרק 4 את מנתח הPE למנהל התהליכים. הלקוח מבקש לבדוק קובץ ולבצע worker מתוך קבוצת תוכניות מעבדה ידועה. תוצאת הבדיקה ותוצאת ההרצה נשמרות יחד עם זהות הקובץ ומזהה ניסיון.

ההרחבה מעבר למעבדות היא החלפה מקבילית של קובץ בזמן הבדיקה, כמה ילדים פעילים ושרשרת restart מוגבלת. התוכנית אינה רשאית להבטיח שהbytes שנבדקו הם בהכרח אלה שנטענו רק מפני ששני השלבים השתמשו באותה מחרוזת נתיב.

מגדירים trust של תיקיית ההפעלה, חוזה פתיחת הקובץ ומדיניות קבצים משתנים. כל ילד נוצר לתוך מסלול job מבוקר, ירושת handles מוגבלת במפורש ומספר ניסיונות restart חסום. ילד שנכשל לפני readiness אינו מדווח כפעיל.

הבדיקות כוללות PE פגום, קובץ שנעלם, ילד שקורס מיד, ילד שמתעלם מסיום וhandle שלא אמור לעבור אליו. מצרפים dump או trace שמוכיח איזה קובץ וגרסה הורצו בפועל. משווים מצב handles ותהליכים אחרי מחזורים רבים, בלי להשתמש בPID לבדו כזהות קבועה.

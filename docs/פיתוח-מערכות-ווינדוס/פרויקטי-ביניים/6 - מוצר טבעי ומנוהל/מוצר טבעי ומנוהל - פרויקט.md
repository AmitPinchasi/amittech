# פרויקט מוצר טבעי ומנוהל

נרחיב אחרי פרק 12 את מנוע הC ABI למוצר בשתי גרסאות. הclient המנוהל הישן צריך להמשיך לעבוד מול הספרייה החדשה בתוך החוזה, והclient החדש צריך לזהות capability חסר בספרייה הישנה.

מוסיפים סוג עבודה, result בעל גרסה וcallback שמגיע אחרי בקשת cancel. מחזיקים context עד join, בודקים סגירת UI ומזריקים כשל בזמן יצירת פעולה. החוזה כולל calling convention, רוחבי מספרים, ownership וקודי שגיאה.

מגישים מטריצה של שתי גרסאות client ושתי גרסאות ספרייה, עם תוצאה צפויה לכל צירוף. מוסיפים בדיקות layout בשני הצדדים וחקירה של root מנוהל שנשאר אחרי סיום פעולה.

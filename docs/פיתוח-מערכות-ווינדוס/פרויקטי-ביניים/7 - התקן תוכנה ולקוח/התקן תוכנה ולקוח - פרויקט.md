# פרויקט התקן תוכנה ולקוח

נרחיב אחרי פרק 13 את התקן התוכנה עם סוג בקשה אסינכרוני נוסף ולקוח אבחון. הservice מחזיק interface מורשה, והdriver מציע פעולות מוגבלות שאפשר לתאר בלי pointer שרירותי או ביצוע קוד חופשי.

ההרחבה מוסיפה גרסת IOCTL, קיבולת תור וסגירת handle בזמן פעילות. מזריקים cancel, remove וכשל הקצאה סביב מעבר בעלות על request. בודקים גם client ישן מול driver חדש.

הבדיקות מתבצעות בVM עם debugger וVerifier לפי הפרק. מגישים גרסת WDK, build, symbols ותוצאות שמבדילות בין בדיקה שבוצעה לבין מסלול שנבדק רק בקריאת קוד.

# פרויקטי ביניים

הפרויקטים מרחיבים את מעבדות הפרקים ומחברים בין המנגנונים שכבר למדנו. לכל פרויקט יש מפרט, תנאי קבלה ופתרון שמסביר את התכנון ואת הראיות הנדרשות. אלה עבודות עצמאיות נוספות, ואינן הרצאות או פרקים נוספים.

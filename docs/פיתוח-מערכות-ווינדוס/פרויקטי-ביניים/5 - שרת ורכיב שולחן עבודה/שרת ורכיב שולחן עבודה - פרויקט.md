# פרויקט שרת ורכיב שולחן עבודה

נרחיב אחרי פרק 10 את השירות ללקוח COM ולממשק native, עם בקשת HTTPS מוגבלת אל שרת מעבדה. הממשק צריך להישאר מגיב כשהשרת איטי, והזהות שנבדקה בTLS צריכה להתאים ליעד שביקשנו.

מגדירים apartment לכל interface וחוזה תוצאה לכל בקשה. לא מעבירים interface pointer גולמי בין apartments בלי מסלול תקין. ההרחבה כוללת סגירת חלון בזמן קריאה, server crash, תשובה גדולה מהמגבלה וcertificate שאינו מתאים ליעד.

הtrace מקשר לחיצה, קריאת COM, ניסיון רשת ותוצאה באמצעות מזהים. מוסרים חבילה שמותקנת במכונה ללא IDE וסמלים שמאפשרים לחקור אותה. בודקים rollback עם נתוני עבודה קיימים.

ההגנה כוללת תקיעה בSTA ותקלה בלתי תלויה ברשת. צריך להציג שני הסברים ושני תיקונים אם יש שתי סיבות, ולא להסתפק בשינוי timeout שמסתיר את שתיהן לזמן קצר.

# תרגול סביבת דרייבר

הקימו VM עם snapshot, debugger וסמלים, ובנו את הדרייבר המינימלי ב־WDK הנעול. הציגו את מזהה build, נתיב ה־sys וה־PDB וסביבת היעד. אין לטעון את הדרייבר על מערכת העבודה הראשית.

הציבו breakpoint ב־DriverEntry וב־Unload. תעדו stack, process context ו־IRQL בכל נקודה. הסבירו מדוע שוויון במקרה המסוים בין process נראה לעין לבין האפליקציה שלכם אינו חוזה לכל callback עתידי.

כתבו רשימת שלוש תלויות שנראו נוחות בקוד משתמש אך אינן מותרות אוטומטית ב־kernel. לכל תלות הציעו חלופה מתוך WDK או שינוי ארכיטקטורה שמחזיר את העבודה ל־user mode.

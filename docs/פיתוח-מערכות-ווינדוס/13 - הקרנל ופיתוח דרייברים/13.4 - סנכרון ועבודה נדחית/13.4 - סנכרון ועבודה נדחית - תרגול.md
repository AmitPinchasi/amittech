# תרגול תור ועבודה נדחית

בדקו את התור עבור מילוי מלא, דחיית אירוע נוסף, ריקון ו־wraparound. הגדירו מדיניות מונה dropped שמוגן תחת אותו lock, בלי להוסיף הקצאה במסלול push.

תכננו דגל WorkerScheduled שמונע יצירת מספר workers מיותרים, אך אינו מאבד אירוע שמגיע בזמן שהצרכן מסיים. כתבו את ההחלטות שמתבצעות תחת lock ואת הפעולות שמתבצעות מחוץ לו.

שרטטו teardown של timer שמפעיל DPC וממנו work item. סמנו איזה ביטול עוצר אירועים חדשים ואיזו המתנה מוכיחה שכל context חזר לבעלים לפני free. אל תסתפקו בשדה boolean בשם stopped בלי להגדיר מי רואה אותו ומתי.

# תרגול עבודה ברקע ציור ותצוגה

## תרגיל ראשון - סגירה בזמן עבודה

חברו את `UiWork` לחלון, הציגו progress ותוצאה, וסגרו אותו כשהחישוב עדיין רץ. הגדילו את עומס החישוב אם הוא מסתיים מהר מדי. הוכיחו שהUI ממשיך לעבד הודעות עד שהworker עובר למצב סופי, ושאין גישה לstate אחרי הריסתו.

## תרגיל שני - משאבי ציור לפי DPI

צרו font לפי DPI והציגו טקסט מעורב בעברית ובאנגלית. העבירו את החלון בין מסכים או שנו scaling בסביבת המעבדה. ודאו שהfont הקודם מוחזר מהDC לפני מחיקה, ושמספר אובייקטי GDI אינו עולה בכל repaint.

## תרגיל שלישי - אותה פעולה בלי עכבר

החליפו את ביטול הסגירה בכפתור Win32 תקני לביטול עבודה. הוסיפו שם נגיש, סדר focus ומצב disabled אחרי סיום. בדקו באמצעות מקלדת וכלי UI Automation שהמצב והתוצאה ניתנים להבנה גם בלי לראות את הציור.

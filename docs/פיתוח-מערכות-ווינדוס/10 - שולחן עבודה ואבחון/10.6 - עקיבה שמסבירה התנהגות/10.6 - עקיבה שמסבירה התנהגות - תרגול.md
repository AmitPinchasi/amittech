# תרגול עקיבה שמסבירה התנהגות

## תרגיל ראשון - הפרדת זמן CPU מהמתנה

אספו את התוכנית וסמנו את שני התחומים בכל activity. החליפו את `Sleep` בחישוב נוסף בעל תוצאה נצפית, והשוו CPU וזמן כולל. אל תציגו latency של פעילות אחת כסכום זמן הCPU של כל הthreadים בלי לבדוק מקביליות.

## תרגיל שני - פעילות שעוברת thread

הוסיפו שלב enqueue בthread הראשי ושלב dequeue בworker. העבירו את אותו activity ID דרך אובייקט העבודה והוסיפו attempt ID נפרד. מדדו זמן המתנה בתור בלי להשתמש בthread ID כזהות העבודה.

## תרגיל שלישי - תרחיש אובדן

בנו workload מוגבל שמפיק הרבה אירועים קטנים, והשוו שתי הגדרות buffers וkeyword filtering. תעדו את מספר האירועים שהיישום ניסה להפיק ואת מצב האובדן שהכלים מדווחים. הסבירו מדוע ההפרש לבדו אינו מזהה את הסיבה אם ההקלטה התחילה מאוחר.

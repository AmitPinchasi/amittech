# תרגול נפחים וטיפול בכשל

הוסיפו לכלי שאילתת המקום דוח מובנה שמפריד בין available-to-caller, free-total ושם volume אם התקבל. אל תחליפו ערך שאינו זמין באפס בלי לציין שהשאילתה נכשלה.

כתבו מדיניות retry לפעולת פתיחה לקריאה: אילו שגיאות מותר לנסות שוב, כמה זמן מחכים ומה מדווחים בסוף. הוסיפו בדיקה עם handle מעבדה שמונע שיתוף ומשתחרר בנקודה נשלטת.

בנו backend כתיבה שמצליח לכתוב רק מספר בתים נתון ואז מחזיר כשל. חברו אותו לפונקציית write_all ולמסלול העסקה, ובדקו שלא מתפרסם אישור אחרי כשל באמצע.

הסבירו כיצד retry לפי נתיב יכול להגיע לקובץ אחר, ומה צריך לשמור כדי לזהות את השינוי.

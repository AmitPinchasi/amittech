# תרגול מטמון וגישה ללא אגירה

בנו שתי גרסאות של קריאת קובץ מעבדה: גרסה רגילה וגרסה ללא buffering. בחרו קובץ שגודלו כפולה של יחידת הגישה שנמדדה, ושמרו את שני המימושים לקריאה בלבד.

בדקו במפורש כשל של אורך לא מיושר בתהליך המעבדה שלכם, ושמרו את קוד השגיאה בלי להניח מראש מה יהיה בכל ספק. תקנו את הבקשה לפי המידע שנשאל מן המערכת.

ערכו סדרת מדידות עם אותה כמות נתונים ובאותו היקף מדידה. דווחו בנפרד על הרצה ראשונה וחוזרת, ואל תטענו שההרצה הראשונה בהכרח התחילה עם cache קר לחלוטין.

כתבו מדוע FILE_FLAG_NO_BUFFERING אינו הוכחה לעמידות לאחר אובדן חשמל, ומדוע מדידת MapViewOfFile בלי לגעת בדפים אינה שקולה לקריאת כל הקובץ.

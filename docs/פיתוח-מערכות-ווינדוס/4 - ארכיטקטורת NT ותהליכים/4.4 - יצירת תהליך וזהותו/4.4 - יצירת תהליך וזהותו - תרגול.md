# תרגול יצירת תהליך וזהותו

בנו את התוכנית והסבירו מדוע exit code של הילד הוא שבע בעוד ההורה יכול לסיים בהצלחה. תעדו את חיי שני ה־handles שחזרו.

העבירו את ה־EXE לתיקייה ששמה מכיל רווחים והריצו שוב. השוו את lpApplicationName לשורת הפקודה, והסבירו מה כל אחד מספק.

הוסיפו לילד קריאה למשתנה סביבה שההורה אינו מעביר. בדקו את התוצאה, ואז הוסיפו אותו לבלוק באופן תקין. ודאו שיש double null בסוף.

תכננו הודעת מוכנות עבור ילד שמקצה משאבים במשך זמן לא ידוע. אל תממשו אותה באמצעות Sleep קבוע.

חקרו את ה־PEB של הילד בדיבאגר ואת command line שמופיעה בו. רשמו אילו חלקים הם תצפית פנימית ואילו ניתנים לקבלה באמצעות API נתמך.

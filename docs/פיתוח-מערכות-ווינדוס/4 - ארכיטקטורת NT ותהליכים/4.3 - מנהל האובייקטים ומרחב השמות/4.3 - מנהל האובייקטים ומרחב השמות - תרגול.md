# תרגול מנהל האובייקטים ומרחב השמות

הריצו את ניסוי השכפול והסבירו מדוע SetEvent מצליחה אחרי סגירת המקור. שרטטו שתי רשומות handle ואובייקט אחד, ואז עדכנו את השרטוט אחרי כל סגירה.

החליפו את השכפול ביצירת event חדש ובדקו שאיתות לראשון אינו מסמן את השני. שמרו את שני ה־handles עד סוף ההמתנה.

בנו שתי תוכניות: הראשונה יוצרת event בשם וממתינה, והשנייה פותחת את השם באמצעות OpenEventW ומסמנת אותו. תעדו איזה process מחזיק כל handle ומתי הוא נסגר.

הסבירו מדוע העברת המספר של handle בשורת פקודה אינה שקולה ל־DuplicateHandle. נתחו גם מצב שבו handle נסגר והערך המספרי שלו ניתן מחדש לאובייקט אחר.

כתבו מדיניות להתנגשות בשם: האם פותחים אובייקט קיים, דוחים אותו או בוחרים שם חדש. הסבירו את השלכת האבטחה בלי להניח ששם אקראי הוא מנגנון הרשאות.

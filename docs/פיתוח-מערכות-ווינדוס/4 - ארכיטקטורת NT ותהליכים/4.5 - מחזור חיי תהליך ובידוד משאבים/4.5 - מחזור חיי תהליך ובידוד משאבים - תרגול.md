# תרגול מחזור חיי תהליך ובידוד משאבים

הריצו את הדוגמה במצב שבו הילד מסיים בזמן, ואז הגדילו את Sleep של הילד כך שיופעל timeout. השוו exit status והסבירו מי בחר אותו בכל מסלול.

הוסיפו לילד אובייקט שה־destructor שלו כותב הודעה. השוו סיום רגיל לסיום כפוי, בלי להסתמך על הגעת טקסט buffered כהוכחה יחידה.

השלימו בדיקות שגיאה במסלולי TerminateProcess והמתנה לאחר כשל שיוך. הגדירו מה ההורה מדווח כשאינו יכול להוכיח שהילד הסתיים.

בדקו אם ההורה כבר נמצא ב־job באמצעות IsProcessInJob, ותעדו את ההשפעה על הניסוי. אל תשתמשו אוטומטית ב־breakaway.

תכננו פרוטוקול stop שיתופי עם deadline ו־fallback כפוי. שרטטו את המצבים והסבירו באיזה מצב מותר לשחרר את ה־job handle.

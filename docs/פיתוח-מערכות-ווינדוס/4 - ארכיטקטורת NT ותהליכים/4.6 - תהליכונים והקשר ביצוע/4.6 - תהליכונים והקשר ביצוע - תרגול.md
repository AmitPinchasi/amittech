# תרגול תהליכונים והקשר ביצוע

הריצו את שני העובדים ובדקו את ערכי TLS. הפעילו את worker פעמיים ברצף באותו thread בניסוי נפרד והסבירו את ההבדל.

הזריקו כשל מדומה לפני יצירת העובד השני. ודאו שהראשון הסתיים לפני שההורה חוזר ושכל handle שנרכש נסגר.

שרטטו את מערך work, שתי המחסניות ועותקי TLS. סמנו אילו אזורים משותפים ואילו שייכים לכל thread.

החליפו את המימוש ב־std::jthread תוך שמירת context חי עד אחרי join. השוו בעלות אוטומטית על thread למשמעות של HANDLE גולמי.

תכננו trace שמבדיל בין שני threads שרצים לסירוגין על מעבד לוגי אחד לבין שני threads שרצים בו זמנית על שניים.

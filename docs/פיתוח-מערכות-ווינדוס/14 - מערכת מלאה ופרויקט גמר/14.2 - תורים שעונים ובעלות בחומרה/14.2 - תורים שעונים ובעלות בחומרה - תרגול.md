# תרגול תורים שעונים ובעלות בחומרה

מריצים את מודל הslots ומוסיפים בדיקה לתצפית שחוזרת אחורה, לערך עתידי ולindex מחוץ לטווח. מסבירים למה שלוש הבדיקות שונות מניסיון רגיל להגיש עבודה כשהתור מלא.

מריצים את תוכנית האודיו על endpoint זמין. מחשבים ידנית את מספר הbytes בקיבולת ואת משך המסגרות. מסבירים למה אי אפשר להציג את המספר האחרון כlatency שנמדד.

בוחרים מעבדת התמחות אחת. במעבדת GPU מוסיפים upload ring לדוגמת Direct3D 12 רשמית ומתעדים fence לכל הקצאה. במעבדת אודיו ממלאים render buffer בשקט באמצעות הדגל המתאים ובודקים event driven refill. במעבדת HID משתמשים רק בהתקן בדיקה עם report descriptor ידוע ובודקים ניתוק בזמן בקשה.

מגישים source version של הדוגמה, חוזי בעלות ותיעוד failure אחד. בכל המסלולים אסור להציג ״הקריאה חזרה״ כתחליף לcompletion של הצרכן. מפרטים גם איך מנקים משאבים אם ההתקן או התור אינם מתקדמים.

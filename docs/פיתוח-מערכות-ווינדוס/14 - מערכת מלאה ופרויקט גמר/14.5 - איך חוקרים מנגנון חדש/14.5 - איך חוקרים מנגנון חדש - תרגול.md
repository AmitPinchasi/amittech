# תרגול איך חוקרים מנגנון חדש

מריצים את הניסוי עם ManualContext ושומרים את הפלט. מריצים גרסה נוספת בלי התקנת context ומשווים. בגרסה השנייה לא מוסיפים assert שמחייב thread מסוים או סדר פלט שלא הובטח.

מוסיפים marker לפני Post, אחרי Post, לפני pump ואחרי pump. כותבים את היחסים שהקוד מבטיח ואת היחסים שרק נצפו בהרצה אחת. מסבירים למה Thread.Sleep אינו מוסיף הוכחה ליחס שלא הובטח.

בוחרים פונקציה נוספת מruntime או callback מדוגמת WDK. נועלים גרסה, כותבים השערה, בונים ניסוי קטן ומגישים קישור למקור יחד עם trace. ההשערה צריכה להיות כזאת שפלט אפשרי יגרום לכם לשנות את דעתכם.

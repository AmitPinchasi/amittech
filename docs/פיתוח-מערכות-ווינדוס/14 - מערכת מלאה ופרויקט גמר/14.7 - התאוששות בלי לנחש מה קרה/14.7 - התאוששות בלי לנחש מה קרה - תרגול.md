# תרגול התאוששות בלי לנחש מה קרה

מריצים את המודל ומשנים את היעד כך שבכל קריאה הוא מגדיל total בלי לשמור מזהה. מוצאים את נקודת הקריסה שבה retry משנה את המצב פעמיים. מחזירים את המימוש התקין ומוסיפים בדיקת conflict לאותו מזהה עם amount אחר.

מוסיפים שתי קריסות רצופות, בכל זוג אפשרי של נקודות Cut, ואז ניסיון שלישי ללא קריסה. בודקים שהתוצאה נשארת אחת. מסבירים אילו הנחות אטומיות המודל עדיין אינו בודק.

מתכננים migration משדה amount ביחידות שלמות לשדה של יחידות קטנות יותר. מגדירים בדיקת overflow, schema version והדרך שבה reader ישן מגיב לנתון חדש. מפילים את המיגרציה לפני ואחרי פרסום generation.

בונים טבלת recovery לפרויקט הגמר. בכל שורה מציינים ראיה עמידה, אישור שנשלח ופעולה חוקית לאחר restart. מוסיפים במפורש שורה שבה התוצאה אינה ידועה ואסור לבצע retry אוטומטי ללא חוזה נוסף.

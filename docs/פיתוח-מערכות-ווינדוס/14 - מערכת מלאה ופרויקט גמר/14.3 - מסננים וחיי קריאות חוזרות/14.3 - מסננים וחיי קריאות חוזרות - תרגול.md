# תרגול מסננים וחיי קריאות חוזרות

מריצים את מודל הרישום עם כמה callers ומבצעים עצירה באמצע. שומרים את אובייקט הרישום חי עד שכל callers סיימו. מוסיפים מונה של כניסות שהתקבלו ושל יציאות, ומוכיחים שעם סיום הפריקה המספרים שווים.

משרטטים את הdeadlock שנוצר כשקוראים לstop מתוך lease פעיל. מתקנים את הAPI כך שתהיה פעולה שמפסיקה קבלה ופעולה נפרדת שממתינה. מתעדים מאילו הקשרים מותר לקרוא לכל אחת.

במעבדת minifilter ממפים init, registration, instance setup, preoperation, postoperation, teardown וunload. לכל שלב מביאים חוזה מתיעוד הגרסה שבה עובדים. בודקים תור מלא ופריקה תחת עומס בVM עם kernel debugger.

משווים את המפה למסלול WFP אחד שנבחר במפורש. מציינים מה נמצא בmanagement plane, מה נמצא בנתיב הקריאה החוזרת ומה קורה למדיניות אם הcallout אינו זמין. אין להניח שכל שכבה וכל סוג filter משתמשים באותה ברירת מחדל.

# ספרים להורדה

כל קורס באתר זמין גם כספר PDF להורדה. הספר מכיל את כל השיעורים של הקורס לפי הסדר, עם תוכן עניינים, ופתרונות התרגילים נמצאים בסוף הספר.
הסרטונים לא נכנסים לספר, אז במקום כל סרטון יש קישור לצפייה בו.
